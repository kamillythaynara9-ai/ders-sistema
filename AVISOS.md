# Avisos de produção

Este pull request não é para ser mesclado. Ele serve de canal de avisos:
quando um pedido é aprovado (ou recebe ajuste) no Sistema DERS, o banco
comenta aqui só o código do pedido, e isso avisa o Claude na hora para
começar a criar o protótipo e o vídeo.

Nenhum dado de cliente é publicado aqui: só o código do pedido.
